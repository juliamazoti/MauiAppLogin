# 🔐 **App de Login**

Projeto desenvolvido na disciplina **Desenvolvimento para Dispositivos Móveis 2**,  
com o professor **Tiago Silva**.  

## 📱 **Sobre o projeto**

- Implementação de um sistema básico de login.  
- Usuário informa **nome** e **senha** para autenticação.  
- Ao validar os dados, o app armazena o login.  
- Redireciona o usuário para uma página protegida após o login.  

## 🛠️ **Tecnologias**

- .NET MAUI  
- C#
